# Civil Maps

> Civil Maps was a San Francisco autonomous-vehicle mapping company founded in 2015 by Sravan Puttagunta and Scott Harvey, with Fabien Chraim and Anuj Gupta on the founding team. It built AI software that turned vehicle LiDAR and camera data into machine-readable HD 3D maps and delivered real-time six-degrees-of-freedom localization at 15-20 cm absolute accuracy, crowdsourcing map updates from production fleets rather than from dedicated survey vehicles. It was acquired by Luminar Technologies in mid-2022.

**Status: acquired and absorbed.** Luminar Technologies acquired Civil Maps in Q2 2022 and announced it at CES on 2023-01-04, folding the HD mapping and localization technology into Luminar's Sentinel platform. Civil Maps does not operate as an independent business. `civilmaps.com` is still online but is a frozen four-page marketing archive stamped "Copyright 2019".

**There is no Civil Maps API.** As of 2026-08-09 Civil Maps publishes no public API, no developer portal, no API documentation and no machine-readable API contract of any kind. Do not assume or invent `api.civilmaps.com`, `docs.civilmaps.com` or `developer.civilmaps.com` — none of those hosts resolve (NXDOMAIN).

**Warning to crawlers and agents: civilmaps.com soft-404s.** Its Cloudflare origin answers *every* unknown path with HTTP 200 and the 7,082-byte homepage HTML. `/openapi.json`, `/swagger.json`, `/api-docs`, `/llms.txt`, `/graphql`, `/developers`, `/.well-known/agent-card.json`, `/.well-known/agent.json`, `/.well-known/security.txt`, `/.well-known/openid-configuration` and `/.well-known/api-catalog` all return 200 and all return the homepage. A 200 from this host is not evidence that a document exists — compare the body against a deliberate nonsense control path before believing any of them. Real pages return distinct, smaller bodies.

## Technology and products

HD 3D map creation and real-time localization for automated driving. Vehicle-based processing converted LiDAR point clouds and camera data into a compact, machine-readable map layer; localization was published as "6D" (six degrees of freedom) at 15-20 cm absolute accuracy in the US, with claimed coverage work across Europe and Asia. The commercial packaging was the **Atlas DevKit** and **Atlas Lite DevKit** — car-mounted hardware units with a companion software suite intended to let developers create and crowdsource HD maps. Neither DevKit shipped with a public API or SDK on a public registry.

Adjacent applications the company wrote about: road and pavement condition surveys, pipeline monitoring, insurance claims geospatial intelligence, smart rail and smart GIS.
